# 神保町異聞録 — 紙と香辛料の街

GPT6 Astraにつくらせたものです。
神保町を参考にした街で、古書とカレーを巡る探索・収集RPGです。ゲーム本体は **`jimbocho-rpg.html` 1ファイル**。ビルド・npm・ローカルサーバーは不要です。

## 起動

`jimbocho-rpg.html` をダブルクリックし、ブラウザで開いてください。

Three.js 0.160.1、OrbitControls、GLTFLoaderをCDNから読み込みます。CDNやWebGLを利用できない場合は内蔵2Dモードへ切り替わり、同じ物語・収集・売買を最後まで遊べます。PLATEAUデータの読み込みは任意で、標準では内蔵データから街区を生成します。

## 最初の進め方

1. 「街へ出かける」を選び、しおりとの会話で「断片の話・進行」を選択します。
2. 一貫堂で「本の山を探す」に挑戦し、店主へ戻って断片の話を聞きます。
3. HUDと手帖に表示される条件を満たし、5枚の断片を集めます。
4. 最後に喫茶 余白へ戻るとエンディングです。クリア後も探索できます。

所持金が足りなければ手帖から配達を受注できます。目的の店で会話すると350円を受け取れます。喫茶 余白では無料で回復できます。

## 内容

- 古書店10軒、古書30冊、10ジャンル、3段階のレアリティ。
- 掘り出し物のタイミングゲーム、売買、3手の値切り交渉。
- 初発見による永続強化、3系統の読書スキル。
- カレー店6軒、HP・活力回復、180秒の一時効果、図鑑。
- 19人のNPC、5断片のメインクエスト、エンディング、実績。
- 昼夜サイクル、雨、ミニマップ、建物のInstancedMesh描画。
- localStorageによる自動保存と、セーブJSONの書き出し・読み込み。

街路と敷地は神保町を参考に縮約した創作地図です。店名・人物・物語は架空です。

## 保存

行動時とプレイ時間10秒ごとに自動保存します。保存枠は1つです。ブラウザの設定やローカルファイルの保存先によってはlocalStorageが利用できない、または保存内容が引き継がれない場合があります。

ファイルを移動する前や別のブラウザへ移る前は「設定・データ」からセーブを書き出してください。旧配置のHTMLで保存していた場合、移動後に「つづきから」が表示されないことがあります。

## PLATEAUへの差し替え

1. 神保町周辺の小範囲をGLB / glTF、または明示的階層の3D Tilesとして用意します。
2. 関連ファイルをCORS許可付きのHTTPSサーバーに配置します。
3. ゲーム内の「設定・データ」にGLB / glTF / `tileset.json`のURLを入力します。
4. 常用する場合はHTML内の`PLATEAU.url`を設定します。

`PLATEAU`の設定項目：

| 項目 | 用途 |
| --- | --- |
| `url` | 初期読み込みURL。空文字は内蔵街区 |
| `coordinates` | 3D TilesのECEF変換。既定値は`ecef` |
| `origin` | ローカル原点の経度・緯度 |
| `offset` | 表示位置のX・Y・Z補正 |
| `rotation` | Y軸回転、ラジアン |
| `scale` | 表示倍率 |
| `maxContents` | 読み込むコンテンツ数の上限。既定値32 |

単体glTFは交差点原点、メートル単位、X東 / Y上 / Z南を想定しています。3D Tilesはタイルのtransformとb3dmのJSON RTC_CENTERを処理します。暗黙タイル、点群、複合タイル、別途デコーダーが必要な圧縮形式などには対応していません。読み込み失敗時は内蔵街区に戻ります。

ローダーは小範囲のデータ向けの簡易実装です。全国データのストリーミングやカメラ距離によるLOD管理は行いません。店舗・街路・当たり判定は縮約地図のままなので、実データと厳密に合わせるには`ROADS`、`FOOTPRINTS`、各店舗・NPCの座標も調整してください。
